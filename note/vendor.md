# Feature List

- แผนก Purchase เท่านั้นที่สามารถเพิ่ม Vendor ได้
- 1 Vendor ID สามารถมีได้หลาย Code
- 1 Code จะสามารถมีได้แค่ 1 ID เท่านั้น
- ในการเพิ่ม/แก้ไขข้อมูล Vendor จะต้องได้รับการ Approve จาก PUR DIM ทุกครั้ง
- ข้อมูลจะ Update ไปที่ระบบจริงหลังจาก Approve แล้วเท่านั้น
- ข้อมูลสามารถส่งต่อไป เพิ่ม/แก้ไขที่ระบบอื่นได้ ได้แก่ AS400, SCM และ LN โดยที่ Buyer มาแก้ไขที่ Procurement ที่เดียว
